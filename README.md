# Abandoned

Minewind has too many bad actors and pedophiles. This fact means I will no longer play. If you are a Minewind dev, feel free to look at the indev branch. There is decent data that might peak your curiosity. Feel free to use it as you wish


Most of the data dumps that would be needed to build the parsers and packet abstraction layer are all already there. The todo list in indev explains how the stack would work in theory, if you want to fork this repo and build it yourself feel free.


Regardless of it I cant and wont give anyone access to the debugging tool, as it dumps all the packets sent by a server and could easily be used to find exploits, so you'll have to do with whats already published, or build your own NED (Never Enough Debugging) from scratch
